# ESP32-S3 Wireless Game Controller

A custom handheld game controller PCB designed using KiCad.

## Features
- ESP32-S3 microcontroller
- USB-C connectivity
- LiPo battery charging (TP4056)
- Dual analog joysticks
- MCP23017 GPIO expander
- Custom PCB design
- 3.3V regulated power system

## Hardware Used
- ESP32-S3
- TP4056
- AMS1117-3.3
- MCP23017
- USB-C connector
- Analog joysticks
- Tactile switches

## Software
- KiCad
- Arduino IDE / ESP-IDF
